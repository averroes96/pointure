## 11. Windows Keyboard Shortcuts {#raccourcis}

| Key | Action |
| :---: | :--- |
| <kbd>F1</kbd> | POS Sales & Checkout screen |
| <kbd>F2</kbd> | Search product or scan |
| <kbd>Alt + V</kbd> | Layaway & Customer lookup |
| <kbd>Alt + H</kbd> | Park & Resume sale |
| <kbd>Alt + M</kbd> | Drawer cash in / out movements |
| <kbd>F10</kbd> or <kbd>.</kbd> | Confirm & complete sale |
| <kbd>Esc</kbd> | Clear cart or cancel dialog |
