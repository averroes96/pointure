## 11. اختصارات لوحة المفاتيح {#raccourcis}

| المفتاح | الوظيفة |
| :---: | :--- |
| <kbd>F1</kbd> | شاشة المبيعات والكاشير |
| <kbd>F2</kbd> | البحث عن منتج أو مسح الباركود |
| <kbd>Alt + V</kbd> | حجز ودفعة زبون |
| <kbd>Alt + H</kbd> | تعليق واستئناف البيع |
| <kbd>Alt + M</kbd> | حركات الصندوق |
| <kbd>F10</kbd> أو <kbd>.</kbd> | تأكيد وقبض المبيعات |
| <kbd>Échap</kbd> | تفريغ السلة أو إلغاء |
