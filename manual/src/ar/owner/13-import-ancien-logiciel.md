## 13. الترحيل واستيراد البيانات السابقة {#import-ancien-logiciel}

إذا كنت تستخدم برنامجاً سابقاً لإدارة محل الأحذية أو ملفات إكسل، يوفر لك ShoeDZ أدوات استيراد وترحيل تلقائية للبدء الفوري دون الحاجة لإعادة كتابة البيانات يدوياً.

### أ. الاستيراد من البرامج القديمة (ملفات DBF)

تعتمد العديد من محلات الأحذية في الجزائر على برامج قديمة تعمل تحت بيئة DOS أو Windows وتحفظ بياناتها في جداول dBase (`.DBF`). يقرأ نظام ShoeDZ هذه الملفات مباشرة عبر محرك الترحيل المدمج (`legacy_dbf.py`) :

1. انسخ مجلد بيانات برنامجك القديم على فلاش ديسك USB.
2. يتعرف ShoeDZ تلقائياً على الملفات القياسية التالية:
   - `ARTICLEB.DBF` أو `ARTICLE.DBF` : كتالوج الأحذية، الماركات، المقاسات، الباركود وأسعار البيع.
   - `FAMILLE.DBF` : عائلات وفئات السلع.
   - `CLIENT.DBF` أو `CLIENTB.DBF` : دليل الزبائن مع أرقام هواتفهم وديونهم السابقة.
   - `FOURNISS.DBF` و `FOURND.DBF` : دليل الموردين ومستحقاتهم السابقة.
   - `GCPARAM.DBF` : الإعدادات العامة للبرنامج القديم.
3. انتقل إلى **الإعدادات → الاستيراد والترحيل**.
4. انقر على **استيراد قاعدة بيانات DBF**، ثم حدد مجلد الملفات.
5. انقر على **بدء الفحص الأولي** : يستعرض البرنامج عدد الأحذية والمقاسات والزبائن التي تم العثور عليها.
6. انقر على **تأكيد الاستيراد** : تدمج البيانات بالكامل في قاعدة بيانات ShoeDZ الجديدة خلال دقائق.

> 📷 **Capture d'écran :** *معالج استيراد ملفات DBF مع فحص عدد المنتجات والزبائن المكتشفة.*

### ب. الاستيراد المجمع عبر جداول Excel / CSV

إذا كانت بياناتك مخزنة في جداول إكسل:
1. في **الإعدادات → الاستيراد والترحيل**، انقر على **استيراد عبر Excel / CSV**.
2. حمّل **نموذج الإكسل القياسي** المعتمد للتأكد من توافق الأعمدة:
   - `reference` : المرجع أو كود المصنع.
   - `nom` : اسم الموديل (مثال: *"حذاء لوفر جلد رجالي"*).
   - `marque` : اسم العلامة التجارية.
   - `pointures` : سلسلة المقاسات (مثال: `39-45` أو `40,41,42,43,44`).
   - `couleur` : اللون.
   - `prix_achat` : تكلفة الشراء بالدينار الجزائري.
   - `prix_vente` : سعر البيع للجمهور بالدينار الجزائري.
   - `stock_initial` : عدد الأزواج المتوفرة في البداية.
3. املأ الملف ببياناتك وارفعه إلى ShoeDZ.
4. **الفحص المبدئي (Dry-run) :** يفحص البرنامج كل سطر وينبهك لأي بيانات غير مكتملة أو مقاسات خاطئة لتصحيحها قبل الحفظ النهائي.
5. اعتمد الاستيراد ليتم تحميل دليلك كاملاً في ثوانٍ.
