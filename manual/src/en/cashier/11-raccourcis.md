## 11. Windows Keyboard Shortcuts Guide {#raccourcis}

All function keys and shortcuts listed below operate continuously across the Windows desktop application. They remain active even when your cursor is positioned inside a search bar, quantity field, or barcode input.

### POS & Direct Sales

| Key | Associated Action | Practical Usage |
| :---: | :--- | :--- |
| <kbd>F1</kbd> | **New Sale / POS Screen** | Switch instantly to the checkout sales screen (or <kbd>Alt + 1</kbd>). |
| <kbd>F2</kbd> | **Product Search** | Places the cursor in the search box to type a shoe model or scan (or <kbd>Alt + 2</kbd>). |
| <kbd>Alt + V</kbd> | **Deposit & Customer** | Opens customer search and activates the down payment / layaway mode. |
| <kbd>Alt + H</kbd> | **Park Sale & Resume** | Sets aside the active cart or resumes a previously held sale. |
| <kbd>Alt + M</kbd> | **Cash Drawer Movements** | Logs cash in or cash out from the drawer (or <kbd>Ctrl + M</kbd>). |
| <kbd>Esc</kbd> | **Clear Cart / Cancel** | Clears the active search or empties the cart upon confirmation. |
| <kbd>F10</kbd> or <kbd>.</kbd> | **Confirm & Checkout** | Finalizes payment and triggers drawer opening (numpad decimal dot key). |
| <kbd>F11</kbd> | **Full Screen Mode** | Maximizes ShoeDZ to fill the monitor and hide the Windows taskbar. |

---

### Management & Documents

| Key | Associated Action | Practical Usage |
| :---: | :--- | :--- |
| <kbd>F3</kbd> | **Invoices** | View the sales invoices list (<kbd>Shift + F3</kbd> to create a new invoice). |
| <kbd>F4</kbd> | **Customers** | Browse the customer directory and accounts (<kbd>Shift + F4</kbd> for a new customer). |
| <kbd>F6</kbd> | **Delivery Notes** | Access shipping and delivery slips (<kbd>Shift + F6</kbd> for a new delivery note). |
| <kbd>F7</kbd> | **Drawer Closing** | Open the end-of-shift closing and Z-Report screen directly (or <kbd>Alt + 7</kbd>). |
| <kbd>F8</kbd> | **Product Catalog** | View inventory quantities and retail prices per variant (or <kbd>Alt + 8</kbd>). |
| <kbd>F9</kbd> | **New Product** | Create a new product record (managers only, or <kbd>Alt + 9</kbd>). |

---

### General Navigation & System

| Key | Associated Action | Practical Usage |
| :---: | :--- | :--- |
| <kbd>F5</kbd> | **Sidebar Navigation** | Expands or collapses the left navigation panel. Use <kbd>↑</kbd> <kbd>↓</kbd> and <kbd>Enter</kbd> to navigate. |
| <kbd>Alt + P</kbd> | **Settings** | Opens store configuration and printer settings (or <kbd>Ctrl + ,</kbd>). |
| <kbd>F12</kbd> | **Help & Shortcuts** | Displays the quick help and keyboard shortcuts modal at any time. |

> [!TIP]
> On a standard keyboard with a dedicated numeric keypad, you can ring up an entire sale without touching the mouse: type the shoe reference, press <kbd>Enter</kbd>, press <kbd>.</kbd> then <kbd>Enter</kbd> to confirm cash payment.
