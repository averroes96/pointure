## 11. دليل اختصارات لوحة المفاتيح في Windows {#raccourcis}

تعمل جميع مفاتيح الاختصار الموضحة أدناه بشكل مستمر في بيئة نظام Windows، وتظل فعالة حتى وإن كان مؤشر الكتابة موضوعاً داخل حقل البحث، أو خانة الكمية، أو حقل الباركود.

### الصندوق والبيع المباشر

| المفتاح | الوظيفة المرتبطة | الاستخدام العملي |
| :---: | :--- | :--- |
| <kbd>F1</kbd> | **بيع جديد / شاشة نقطة البيع** | الانتقال الفوري إلى شاشة البيع والتحصيل (أو <kbd>Alt + 1</kbd>). |
| <kbd>F2</kbd> | **البحث عن منتج** | وضع المؤشر داخل خانة البحث لكتابة الاسم أو مسح الباركود (أو <kbd>Alt + 2</kbd>). |
| <kbd>Alt + V</kbd> | **العربون والزبون** | فتح البحث عن الزبون وتفعيل وضع الدفعة الجزئية / الحجز. |
| <kbd>Alt + H</kbd> | **تعليق البيع والاستئناف** | وضع السلة الحالية جانباً أو استرجاع سلة معلقة. |
| <kbd>Alt + M</kbd> | **حركات الصندوق** | تسجيل حركة إيداع أو سحب نقدي من الدرج (أو <kbd>Ctrl + M</kbd>). |
| <kbd>Échap</kbd> | **تفريغ السلة / إلغاء** | مسح حقل البحث أو إفراغ السلة الحالية بعد طلب التأكيد. |
| <kbd>F10</kbd> أو <kbd>.</kbd> | **تأكيد والتحصيل** | اعتماد الدفع وفتح درج الصندوق (زر النقطة في لوحة الأرقام). |
| <kbd>F11</kbd> | **ملء الشاشة** | تكبير تطبيق ShoeDZ على كامل الشاشة لإخفاء شريط مهام Windows. |

---

### الإدارة والمستندات

| المفتاح | الوظيفة المرتبطة | الاستخدام العملي |
| :---: | :--- | :--- |
| <kbd>F3</kbd> | **الفواتير** | الوصول إلى قائمة الفواتير (<kbd>Shift + F3</kbd> لإنشاء فاتورة جديدة). |
| <kbd>F4</kbd> | **الزبائن** | استعراض دليل الزبائن وحساباتهم (<kbd>Shift + F4</kbd> لإنشاء زبون جديد). |
| <kbd>F6</kbd> | **وصولات التسليم** | قائمة وصولات التسليم والشحن (<kbd>Shift + F6</kbd> لوصل جديد). |
| <kbd>F7</kbd> | **إغلاق الصندوق** | الانتقال مباشرة إلى شاشة الإغلاق اليومي وتقرير Z (أو <kbd>Alt + 7</kbd>). |
| <kbd>F8</kbd> | **دليل المنتجات** | استعراض كميات المخزون وأسعار البيع لكل مقاس ولون (أو <kbd>Alt + 8</kbd>). |
| <kbd>F9</kbd> | **منتج جديد** | إنشاء بطاقة حذاء أو منتج جديد (مخصص للمشرفين، أو <kbd>Alt + 9</kbd>). |

---

### البيع بالجملة والاختصارات السريعة

| المفتاح | الوظيفة المرتبطة | الاستخدام العملي |
| :---: | :--- | :--- |
| <kbd>Ctrl + K</kbd> | **البحث الشامل والأوامر** | البحث عن المنتجات والزبائن والموردين النشطين؛ يظهر موقع المنتج حسب الفرع المحدد. تظهر الفواتير في خطتي Pro Wholesale وEnterprise. |
| <kbd>Alt + G</kbd> | **تبديل سعر الجملة** | التبديل الفوري بين سعر التجزئة ونصف الجملة والجملة في السلة النشطة. |
| <kbd>Alt + C</kbd> | **البيع بالكرتون** | فتح نافذة الإدخال السريع بالكرتون وتوزيع المقاسات. |
| <kbd>Alt + D</kbd> | **عروض الأسعار والبروفورما** | قائمة عروض الأسعار (<kbd>Shift + Alt + D</kbd> لإنشاء عرض سعر جديد). |
| <kbd>Alt + B</kbd> | **طلبيات الشراء للموردين** | قائمة طلبيات الشراء (<kbd>Shift + Alt + B</kbd> لإنشاء طلبية شراء جديدة). |
| <kbd>Alt + R</kbd> | **كشف حساب الزبائن** | استعراض الديون والأرصدة المستحقة ودفتر حساب الزبائن. |

---

### التنقل العام وإعدادات النظام

| المفتاح | الوظيفة المرتبطة | الاستخدام العملي |
| :---: | :--- | :--- |
| <kbd>F5</kbd> | **القائمة الجانبية** | طي أو فتح شريط التنقل الجانبي. استخدم بعدها أسهم <kbd>↑</kbd> <kbd>↓</kbd> وزر <kbd>Entrée</kbd>. |
| <kbd>Alt + P</kbd> | **الإعدادات** | فتح إعدادات المتجر وتهيئة الطابعات (أو <kbd>Ctrl + ,</kbd>). |
| <kbd>F12</kbd> | **المساعدة والاختصارات** | إظهار نافذة المساعدة السريعة وقائمة الاختصارات في أي وقت. |

> [!TIP]
> باستخدام لوحة مفاتيح قياسية مزودة بلوحة أرقام جانبية، يمكنك إتمام عملية بيع كاملة دون الحاجة للمس الفأرة: اكتب المرجع أو امسحه، اضغط على <kbd>Entrée</kbd>، اضغط على زر النقطة <kbd>.</kbd> ثم اضغط <kbd>Entrée</kbd> لتأكيد استلام النقد وطباعة الوصل.
